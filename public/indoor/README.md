# 店内散步

从外侧建筑的门进入，首次停在爷爷柜台。滚轮或触控板横向逛店，手机左右滑动，也可点击底部四个柜台名称直达。鼠标移动会驱动背景、店长、柜台、门帘的不同位移与惯性。

爷爷提供本地对白和写信入口；刺身、甜品、抹茶柜台提供趣味菜单。点单、制作、品尝、收起只改变本次访问状态，没有支付或真实订单。音乐、番茄钟在进出店铺时继续运行。

信纸沿用既有写信流程。折好后仍在店内，不会发起网络请求；返回街角点击红色邮箱才投递。场景切换保留草稿、待寄信、回信和各柜台饮食状态。对话或书写时暂停场景滚动，Escape 可关闭对话，减少动态效果模式关闭视差。

## 资源

原 JPG 不变；生成的分层 PNG 与物件图集保存在 `source/`。`scenes.json` 记录统一画布、各层 URL、深度、层级与边界。网页加载 `optimized/` 中的 16 张独立 WebP 图层和四张饮食贴图，`previews/` 是叠加检查图。

运行 `npm run prepare:indoor` 可从已保存的源图集重建 WebP、清单与预览，不会重新调用图像生成服务。生成方式、完整提示词和与原图的偏差见 [GENERATED-ASSETS.md](./GENERATED-ASSETS.md) 和 [GRANDPA-ASSETS.md](./GRANDPA-ASSETS.md)。

## 检查

`npm run lint`、`npx tsc --noEmit`、`npm run build`。浏览器重点检查店门进出、四柜台导航与视差、菜单与品尝、对话暂停滚动、室内折信后到门外投递，以及桌面和手机布局。旧独立猫店长入口与回信选项已移除，历史回信保留读取兼容。
