# 后续产品待办

## 上传图片后自动制作场景资源

目标：上传室外与室内原图 → 识别主体及交互位置 → 拆分图层 → 补全被遮挡的背景 → 生成透明资源和场景清单 → 用户预览、调整并确认 → 发布成对场景。

先单独验证图层拆分、背景补全和布局质量；不能仅通过矩形裁剪声称已完成自动制作。复用现有 `image` / `layers` 场景接口，保留原图与资源版本；生成失败、费用或效果不合适时继续使用整图。未经用户确认，生成结果不能替换已发布的小店。

当前脚本仅处理已经制作好的图集，首版的上传使用整图，不依赖上述生成能力。
