# 网站中的水彩街角

首页由 `components/scene/ExteriorScene.tsx` 驱动，是单屏可探索场景，没有章节或滚动推进。指针坐标经归一化后，用 GSAP quickTo 控制远景、建筑、独立邮箱与植物的差速位移和延迟，离开场景后缓慢回正。触屏可按住移动探索，减少动态效果模式关闭视差。左侧显示所在地、天气、温度与时间；场景自动跟随当地时间与天气。右上角预留用户中心，未接入时明确显示暂未开放。

## 自动昼夜与天气

`useSceneEnvironment` 通过环境订阅管理浏览器定位、请求与计时器。每次页面挂载只请求一次低精度定位（React Strict Mode 重启 Effect 时复用定位 Promise），不追踪移动、不持久保存坐标。生产站点需要 HTTPS 才能使用浏览器定位；localhost 开发环境也支持。定位拒绝、不支持或 8 秒超时后按设备时间显示，不阻塞场景。

同源 `GET /api/weather?latitude=…&longitude=…` 校验坐标，向 Open-Meteo 请求气温、WMO 天气代码、昼夜标志和昨天、今天、明天的日出日落，覆盖跨午夜的清晨与黄昏。返回 UTC 毫秒时间戳及所在地时区；请求不缓存，8 秒超时。天气每 15 分钟更新，时段每分钟检查；后台暂停刷新，回到页面立即检查过期状态。卸载会取消请求并清理计时器、监听器。失败保留最近 30 分钟内的观测，之后退回设备时间；无有效天气时不显示天气种类。

清晨取日出前 30 分钟至日出后 60 分钟，黄昏取日落前 60 分钟至日落后 30 分钟；其余按日出日落划分白天与夜晚，极昼极夜使用服务商昼夜标志。设备时间回退规则为 05–08 清晨、08–17 白天、17–19 黄昏、其余夜晚。

晴、多云、阴、雨、雪、雾、雷雨独立叠加在时段色调上，使用 CSS 云雾与少量细雨／雪粒子；夜间阴雨雪雾弱化月亮、隐藏星光。雷雨只增加暗色雨景，不闪电。装饰层不拦截点击，减少动态效果模式隐藏雨雪粒子，保留静态色调与云雾。店内、音乐与投递流程不随天气修改。

天气数据来源：[Open-Meteo](https://open-meteo.com/)；数据许可：[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。页面有有效天气时显示来源链接。默认公共接口适用于非商业用途；商业部署应按 Open-Meteo 许可接入对应服务。

## 素材处理

运行 `npm run prepare:scene`，脚本读取 `layers.json`，保留原图不动，生成 `optimized/` 中的 WebP 和裁切坐标。裁切局部透明空白，保留软边外扩 10px，不重绘原画。底图加 11 个局部层合计约 530 KiB，原 PNG 总计约 13.5 MiB。

建筑局部按 1080 原画坐标定位，相对底图位移不超过 1 个 CSS 像素。天空最大反向移动 15px、建筑 17px、前景邮箱 42px、植物 58px，构成真实独立的景深平面。各平面的缓动时长不同，产生惯性和时差。物件上的水彩笔触与不规则轮廓保留。

## 写信与投递

点击红色邮箱取信纸，键盘输入的文字沿纸张横线排布，长内容让整张纸自然延展。可选标题、收信人与隐私在纸面或纸张下方调整。

“折好信纸”只执行折纸与装信封动画，然后进入 `envelopeReady`，不发送请求。返回场景后点击实体邮箱，才由 `services/letters/deliverLetter.ts` 发起网络请求，信封飞向真实投口并消失。等待完成后邮箱露出回信。失败保留信件，允许修改或再次点击投递；双击不会重复发送。

独立邮箱和前景草丛由内置 imagegen 生成，原 PNG 保存在 `assets/`，网站使用压缩 WebP。完整提示词与输出路径见 `GENERATED-ASSETS.md`。

## 当前素材边界

原始局部图层的 alpha 正常，但透明像素仍保留 RGB。忽略 alpha 的预览器可能显示整栋建筑。局部层与底图内容重复，尚未完成精细抠图和遮挡补绘，因此不能扩大自行车、雨棚、招牌的位移。未来替换为精修资源时，可调整 `depths` 和镜头参数；请先确保底图已移除对应物体并补齐被遮挡区域。

## 验证

`npm test`、`npm run lint`、`npx tsc --noEmit`、`npm run build`。测试使用 Node.js 22.15+ 的原生测试与模块钩子，不新增测试框架依赖。浏览器检查桌面与手机画面、各时段及天气、定位允许／拒绝、后台恢复、指针差速、纸张输入与折叠、通过实体邮箱投递和取回回信。系统启用减少动态效果时关闭景深与天气粒子运动，以最小反馈完成折信和投递。

当前后端无 AI 密钥时返回本地示例回信。音乐通过用户点击后启动 Web Audio，本地生成雨声与低音环境音，不依赖第三方音频资源。

## 店内的声音与专注物件

店内音乐与专注入口位于柜台陈设中：爷爷柜台是录音机与旧座钟，刺身店是小电视与厨房计时器，甜品屋是唱片机与小闹钟，抹茶店是木壳收音机与茶席计时钟。音乐在物件附近展开纸签；专注统一在右侧展开约 240px 宽的留时纸页。两者互斥，点击空白、再次点击入口或 Escape 收起，关闭后恢复可用入口的焦点。店外音乐仅显示当前曲名、播放／暂停和音量，不提供选曲。

各店曲目在 `domain/companions.ts` 配置，曲目元数据及预留音频地址字段位于 `domain/musicTracks.ts`。目前共用两种本地环境声；后续提供 OSS 音频地址后再接入真实音频，填写 `src` 本身暂不会改变现有合成声音。

`CompanionRuntime` 在页面中仅挂载一次，分别管理单一音频实例与专注时钟。换柜台、进出店、写信或打开店员对话只关闭纸签，不中断播放和计时。计时沿用 25 分钟，结束后安静显示完成状态。物件与纸签控件不触发柜台滑动，磁吸阈值保持 20%。店内时钟指针表示共享专注进度，不再重复悬挂数字标签。店外闲置时在右下边缘露出竖排“专注片刻”；计时开始后跨场景收纳为小号时间与细进度线。暂停与完成只改变书签状态，写信、阅读回信和店员对话时隐藏书签，计时继续。减少动态效果时关闭唱片旋转。

可选浏览器回归：安装或使用环境提供的 Playwright，启动网站后执行 `npm run test:browser`。支持用 `PLAYWRIGHT_MODULE` 指定 Playwright 模块路径、`BROWSER_EXECUTABLE` 指定浏览器、`WEATHER_TEST_URL` 指定站点地址（默认 localhost:3000）、`WEATHER_SCREENSHOT_DIR` 保存截图。脚本模拟四个时段与七类天气，检查单次定位、移动端布局、减少动态效果和原有场景操作，不依赖当天真实天气。


## 地点、用户入口与待交付素材

定位仍只请求一次。获准后，天气与 BigDataCloud 浏览器逆地理编码并行，二者独立超时（8 秒）和清理；地名不重复轮询，不使用 IP 定位，也不保存坐标。接口固定携带当前坐标及 `localityLanguage=zh`，拒绝服务方明确标记为 IP Geolocation 的结果。城市与区域仅显示接口返回值，不猜测所在地。定位失败显示“本地时间／天气暂不可用”；只有地名失败时天气仍可独立显示。长地名采用正文宋体与两行排版，完整地名保留在标题属性和文本节点中。天气有效时用所在地时区显示时间，否则按设备时间。

地点来源：[BigDataCloud 客户端逆地理编码文档](https://www.bigdatacloud.com/free-api/free-reverse-geocode-to-city-api)。天气和地点署名位于左侧信息底部。`UserCenterEntry` 暴露可选 `user`（昵称、头像）和 `onOpenAccount`；尚未接入时禁用并明确标注暂未开放。本轮不包含 Supabase SDK 或模拟登录。

按用户选择，六张重制水彩素材留待后续提供。本轮保留旧 SVG，已预留 `musicArtwork` / `focusArtwork` 接入口；第一房间两件插画保持原样。交付规格见 `public/indoor/COMPANION-ARTWORK.md`。物件与柜台共用视差深度，移除常驻米色文字牌；桌面靠近或聚焦时提示，手机显示无底色短标签。

无浏览器静态预览：`node --import ./tests/register.mjs scripts/preview-scene-controls.mjs`，输出 `artifacts/scene-controls/index.html`（三间房各桌面／手机合成）。本轮按照用户要求不进行浏览器测试；这些预览仅用于检查艺术落点，不能替代真实浏览器布局验收或水彩贴图验收。
