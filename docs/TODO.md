# 后续产品待办

## 上传图片后自动制作场景资源

目标：上传室外与室内原图 → 识别主体及交互位置 → 拆分图层 → 补全被遮挡的背景 → 生成透明资源和场景清单 → 用户预览、调整并确认 → 发布成对场景。

先单独验证图层拆分、背景补全和布局质量；不能仅通过矩形裁剪声称已完成自动制作。复用现有 `image` / `layers` 场景接口，保留原图与资源版本；生成失败、费用或效果不合适时继续使用整图。未经用户确认，生成结果不能替换已发布的小店。

当前脚本仅处理已经制作好的图集，首版的上传使用整图，不依赖上述生成能力。

## 店铺收藏、可见性与关店（2026-10-16 需求补充）

- 首次登录自动拥有默认小店，默认对外开放并进入随机逛店；店主可修改可见性、关闭和重新开放自己的店铺。
- 增加账号级店铺收藏。关店后，已收藏的用户仍可通过收藏访问并看到关店状态；未收藏用户在左右随机逛店时不再遇到这家店。
- 关店保留原有店铺身份、地址、布置与通信记录。店主可以回到自己的店收信及管理营业状态。
- 关灯动效列为后续待办：店铺灯光逐渐熄灭并呈现关店外观；重新开店时提供对应的亮灯反馈。动效完成前先提供清晰的静态关店状态，不依赖动画表达营业状态，并兼容减少动态效果设置。
- 已确认：关店停止建立新通信，已有通信仍允许双方回信；屏蔽及参与者权限继续生效。
- 已确认的产品结构、导航与分阶段开发顺序见 [小店漫游设计](superpowers/specs/2026-10-16-shop-exploration-design.md)。营业、收藏和静态关店已实现，本地验证与外部待验项见 [验收记录](shop-exploration-acceptance.md)。

## 小店装饰后续（2026-10-16）

本轮已接入独立装饰页、首次引导、三套店主与室内主题、店名与介绍、三种文字牌匾、两种默认音景及独立前景草丛开关。实现与迁移说明见 [装饰验收记录](shop-decoration-acceptance.md)。

- 店主角色与室内自由搭配：先适配角色尺寸、前后遮挡、角色称呼和热点。本轮只提供喵猫刺身、兔子甜品屋、抹茶小店的整套主题，不改变账号头像、通信归属或 AI 回信身份。
- 多款信箱：当前只有一款独立水彩信箱，先补齐样式素材，再适配投递、未读和关闭接信状态。
- 室外自行车、雨棚、盆栽等自由装饰：部分物体烘焙在建筑底图中，需先移除原物体、补绘背景并精修独立图层；本轮只控制已有独立前景草丛。
- 贴纸：准备素材与可放置区域，设计位置、缩放的存储和移动端编辑交互。
- 更多门面、实体牌匾和音乐曲目：补齐素材；图片内已有文字的牌匾需要先处理原图。本轮三种样式只修改现有文字牌匾覆盖层。
- 图片上传和自由布置：本轮不重新开放旧编辑弹窗；后续统一接入独立装饰页，并与上传资源和版本校验联动。
