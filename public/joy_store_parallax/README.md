# 解忧杂货店 — GSAP 视差资源包

包含原始完整建筑透明 PNG 和 11 个可单独驱动的局部图层。所有图层均为 1080×1080、原点对齐。

**注意**：原图为单张栅格图，局部图层通过软边矩形蒙版提取，并非真正的无损抠图；完整建筑底图仍保留所有元素。为避免重复影像，默认只展示底图，其他局部层可按需开启，并建议在正式上线前精修蒙版/补全遮挡背景。

运行：在本目录执行 `python -m http.server 8000`，访问 `http://localhost:8000`。需联网加载 GSAP CDN。

可进一步用 Photoshop/Photopea 修整图层边缘、移除底图中的对应物体，实现更明显的视差。
